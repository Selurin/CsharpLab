
# Лабораторная работа №1: Основы C#

## Описание
Консольное приложение на C#, реализующее набор базовых алгоритмических задач. Программа предоставляет меню для выбора задачи, выполняет валидацию пользовательского ввода и выводит результат вычислений.

## Структура проекта
- **Program.cs**: Точка входа (`Main`). Содержит цикл меню, обработку выбора пользователя и вывод результатов.
- **TaskSolver.cs**: Класс `TaskSolver`, содержащий статические методы для решения всех задач (логика вычислений).

## Как запустить
1. Откройте проект в Visual Studio или VS Code.
2. Убедитесь, что установлены необходимые зависимости (.NET SDK).
3. Запустите программу через терминал:
   ```bash
   dotnet run
   ```
   Или через запуск в среде разработки.
4. Следуйте инструкциям в консольном меню. Для выхода введите `0`.

## Особенности реализации
- Используется строгая типизация и проверка ввода (`TryParse`) для предотвращения ошибок при вводе некорректных данных.
- Логика задач отделена от интерфейса пользователя (класс `TaskSolver`).
