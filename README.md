## Задача 1 (1.1)

### Текст задачи
**Дробная часть.**
Дана сигнатура метода: `public double fraction(double x);` 
Необходимо реализовать метод таким образом, чтобы он возвращал только дробную часть числа х. 
*Подсказка: вещественное число может быть преобразовано к целому путем отбрасывания дробной части.*
Пример: x=5,25 результат: 0,25

### Алгоритм решения
1. Вычисляем «грязную» дробную часть путем вычитания целой части из исходного числа: `x - (int)x`.
2. Чтобы избежать ошибок округления вещественных чисел (артефактов вроде `0.25000000001`), преобразуем исходное число в строку.
3. Разделяем строку по запятой/точке, чтобы определить точное количество знаков после запятой (precision).
4. Ограничиваем точность максимум 15 знаками.
5. Берем модуль от «грязной» дробной части и округляем её до вычисленной ранее точности.
6. Возвращаем полученный результат.

### Текст задачи
**Диапазон.**
Дана сигнатура метода: `public bool isInRange(int a, int b, int num);` 
Метод принимает левую и правую границу(a и b) некоторого числового диапазона. Необходимо реализовать метод таким образом, чтобы он возвращал true, если num входит в указанный диапазон(включая границы).

3. В противном случае вернуть `false`.

5. Третьим циклом скопировать «хвост» исходного массива `arr`, начиная с индекса `pos` до конца, в `result`.
